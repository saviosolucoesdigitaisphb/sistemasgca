Como funciona

1. Os cadastros são salvos localmente no dispositivo (IndexedDB).
2. Quando você apertar "Sincronizar agora", os pendentes vão para o Firestore.
3. A coleção no Firestore se chamará sgca_acessos.
4. Ao abrir o app com internet, baixa automaticamente todos os registros do servidor.
